# Library Management System

A simple Library Management System built using Python and SQLite.

## Features

- Add books
- View books
- Search books
- Add library members
- View members
- Issue books
- Return books
- View transactions
- SQLite database
- Git version control

## Technologies

- Python
- SQLite
- Git
- VS Code
